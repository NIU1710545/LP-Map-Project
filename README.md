# LP-Map-Project
Projecte Universitari portat per la materia Laboratori de Programació de segon any de carrera d'Eninyeria Informatica a la 
Universitat Autònoma de Barcelona

# Descripció (CAT)
Té com a objectiu el desenvolupament d'una aplicació capaç de gestionar punts d'interès i camins en un entorn gràfic,
utilitzant informació extreta de fitxers XML. 

A la primera fase, l'estudiant ha de dissenyar una estructura de dades per emmagatzemar nodes, camins i punts d'interès, 
i mostrar-los en un mapa. 

La segona fase consisteix en implementar algorismes per trobar el camí més curt entre dos punts d'interès, 
emprant estructures com arbres i grafs. L'entorn de desenvolupament utilitzat és Visual Studio 2019 amb suport per C++14.


# Description (ENG) 
It aims to develop an application capable of managing points of interest and paths in a graphic environment,
using information extracted from XML files. 

In the first phase, the student must design a data structure to store nodes, paths and points of interest, 
and show them on a map. 

The second phase consists of implementing algorithms to find the shortest path between two points of interest, 
using structures such as trees and graphs. The development environment used is Visual Studio 2019 with C++14 support.

utilizando información extraída de ficheros XML. 

A la primera fase, el estudiante tiene que diseñar una estructura de datos para almacenar nodos, caminos y puntos de interés,
